## This is
A simple python password generator which takes service, email (or username) of service and generates password; and saves them in MongoDB.

You can specify the length you want for the password as well.


### Basic Usage

You need to do:  
1.Install [MongoDB](https://www.mongodb.com/docs/manual/administration/install-community/)  
2.Install required packages using  
```pip install -r requirements.txt```  
3.Run the script  
```python Main.py```


### Privacy Concerns  
All your information are stored locally and in your own machine.
